One small, typed, read-only API over outbound sending tools: Instantly, Smartlead and HeyReach. What the three share is normalized. Everything else each one can report is still there through a typed catalog of the vendor's own reads. No method writes to a vendor tool, it stores nothing, and it runs no AI model.
