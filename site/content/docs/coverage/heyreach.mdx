Inventoried on 2026-11-14 from HeyReach's public API reference at `https://docs.heyreach.io`: the page index (`llms.txt`) and the machine-readable reference (`openapi.json`), checked against the Postman collection the docs link to (published 2026-09-16, 88 requests, every one of them also in the reference). The reference documents 106 endpoints, all on `https://api.heyreach.io/api/public`: 17 are used by normalized reads, 25 are in the native catalog (`packages/outbound-sdk/src/heyreach/native.ts`), 3 are excluded and 61 are writes.

The five `/management/organizations` reads belong to the Organization Management API. They need the organization API key in place of a workspace key and answer 401 without it. HeyReach documents no sister service on another host.

Two of the excluded rows return secrets. The third, a voice message's audio file, returns a file and not JSON: the request engine reads every response as text, so a binary body cannot be returned intact. It becomes a native read once the engine can hand back bytes.

Five reads stay in the native catalog and are also used by a normalized read. Lookup by profile or email (`leads.lookup`) asks `POST /campaign/GetCampaignsForLead` for the campaigns and, for an email address, `POST /list/GetListsForLead` for a list to find the profile in. `stats.allCampaigns` reads `POST /stats/GetOverallStatsByCampaign`, `lists.get` reads `GET /list/GetById` and `webhooks.get` reads `GET /webhooks/GetWebhookById`.

## Per-lead reply counts and automatic replies

No HeyReach lead shape has a reply count, so `engagement` is `null` on every HeyReach lead. `hotLeads` takes a HeyReach lead's reply count and last reply time from the replies it reads within `recency_days`, leaving out replies flagged automatic. A campaign's leads carry no auto-tag, so where the record has no label it takes the class of the correspondent's newest auto-tag from those replies: an Interested tag earns the interest points while `positive_labels` holds Interested, and the reason reads "marked positive by the vendor".
