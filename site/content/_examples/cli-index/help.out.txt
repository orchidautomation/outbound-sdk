$ outbound help
outbound: read-only access to outbound sending tools

Usage: outbound <command> [options]

  providers
  blocklist [--limit N]
  campaign <id or name> [--stats] [--sequence] [--subsequences] [--settings] [--from YYYY-MM-DD] [--to YYYY-MM-DD] [--by day|total]
  campaigns [--status active|paused|draft|completed|archived] [--search TEXT] [--limit N]
  capabilities
  health <sender id>
  insight [name] [--input JSON] [--card | --slack]  computed answers; no name lists them
  leads [--campaign ID|NAME | --list ID|NAME] [--limit N]
  lists [--limit N]
  limits
  native [name] [--input JSON]   the vendor's own reads; no name lists them
  person <email, LinkedIn URL or lead ref> [--limit N] [--card | --slack]  one person's campaigns across every tool; a lead ref is taken as another command printed it
  replies [--campaign ID|NAME] [--category positive|negative|neutral|ooo|...] [--since ISO] [--limit N] [--bodies] [--by person] [--include-inbox]  one record per message; --by person gives one row per person. --limit defaults to 50, or with --since to the whole window up to 2000. --include-inbox adds conversations outside every campaign (HeyReach)
  senders [--limit N]
  stats [--from YYYY-MM-DD] [--to YYYY-MM-DD] [--by day|total]
  tags [--limit N]
  thread <id> [--bodies]
  tool <name> [--input JSON] [--card | --slack]  without --input, a tool that needs input fails with what it takes (exit 2)
  tools
  webhooks [--campaign ID|NAME] [--limit N]
  mcp [--tools a,b,...]    start a local MCP server on stdio (redact is on); --tools offers only the tools named
  version                  print the installed version (also --version, -v)
  update                   check npm for a newer version and say how to get it

Options:
  --provider <id>          the adapter to use, or all for every provider whose key is set (default: OUTBOUND_SDK_PROVIDER)
  --compact                print JSON on one line
  --raw                    keep each record's raw vendor payload (left out by default)
  --config <file>          load plugins from a file whose default export is defineConfig({ plugins })
  --redact                 mask personal fields (on by default for mcp)
  --no-redact              do not mask personal fields, even for mcp
  --cache <seconds>        reuse an answer for this long, within this process (for mcp; use a config-file store to persist)
  --max-requests <n>       the most vendor requests one command, or one MCP tool call, may make

Each adapter reads its own key from the environment, for example INSTANTLY_API_KEY.
OUTBOUND_REDACT_KEY, a secret of at least 32 characters, gives redact the same tokens in every run.
