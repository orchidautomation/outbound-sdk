The CLI, `outbound mcp` and `fromEnv()` read every vendor whose key is set when no provider is named, as one combined instance, so a person is found across Instantly and HeyReach with nothing to configure. `OUTBOUND_SDK_PROVIDER` still picks one vendor, and now also takes a comma list. New `outbound person <email or LinkedIn URL>`. The CLI installs the identity plugin, so `cross_channel_lead` is served and leads carry `personKey`; `outbound tools` and `outbound tool` now offer the insights, as `outbound mcp` does.
